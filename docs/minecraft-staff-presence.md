# اتصال وضعیت حضور کارکنان Minecraft

وب‌سایت endpoint دریافت رویداد دارد؛ برای اینکه وضعیت آنلاین و زمان حضور کارکنان به‌روزرسانی شود، یک پلاگین سمت سرور Paper/Spigot باید رویداد ورود و خروج را به این endpoint ارسال کند.

## ۱. تنظیم Railway

یک مقدار تصادفی طولانی برای `MINECRAFT_WEBHOOK_TOKEN` بسازید و در Variables سرویس وب تنظیم کنید. این مقدار را در Git، چت عمومی یا لاگ‌های سرور منتشر نکنید.

## ۲. درخواست ورود

به آدرس HTTPS سایت خود درخواست POST بفرستید:

`https://YOUR-DOMAIN/api/minecraft-event`

Headerها:

- `Content-Type: application/json`
- `X-MiladCraft-Token: YOUR_SHARED_SECRET`

بدنه:

```json
{"username":"MinecraftStaffName","event":"join"}
```

## ۳. درخواست خروج

```json
{"username":"MinecraftStaffName","event":"quit"}
```

نام کاربری باید با نام حساب کارکنان در سایت منطبق باشد. حساب‌هایی که هنوز نقش `player` دارند، به‌عنوان کارکنان ثبت نمی‌شوند.

## نکات پلاگین

- درخواست HTTP را در نخ پس‌زمینه بفرستید تا نخ اصلی Minecraft متوقف نشود.
- توکن را در config خصوصی سرور نگه دارید و در لاگ‌ها ننویسید.
- برای خطاهای موقت، retry محدود داشته باشید.
- نام کاربری Minecraft را با مقدار ذخیره‌شده در پروفایل کارکنان هماهنگ کنید.
- این مخزن دریافت‌کننده webhook را فراهم می‌کند؛ پلاگین فرستنده هنوز باید جداگانه نصب و پیکربندی شود.
